# Dataset

The project deliberately does not ship fake training images. Add real, correctly labelled ginger images into the 20 disease folders. Record each image in `image_manifest.json` with filename, disease ID/name, source, license/source information, and verified status.

Do not train a visual class merely because it exists in the knowledge database. Some listed diseases are primarily rhizome/root/soil/storage/internal-tissue problems and may not be reliably diagnosed from a leaf photograph.
